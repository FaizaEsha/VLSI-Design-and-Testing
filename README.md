# VLSI Design and Testing

VHDL design, simulation, and verification labs for **CSE 450 — Design and Testing of VLSI Lab**, Department of Computer Science and Engineering, University of Asia Pacific.

**Conducted by:** Md Rasheduzzaman, Lecturer, Dept. of CSE, UAP

## Overview

This repository documents lab work for CSE 450, carried out using **Xilinx ISE** within a **VirtualBox** environment. Each module is implemented in VHDL and verified through simulation.

## Tools & Environment

- **Design Suite:** Xilinx ISE
- **HDL:** VHDL
- **Environment:** VirtualBox
