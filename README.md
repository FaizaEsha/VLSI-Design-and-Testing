# 🔌 VLSI Design and Testing

> VHDL design and simulation work for CSE 450: Design and Testing of VLSI Lab.

## About

This repository holds my lab work for **CSE 450: Design and Testing of VLSI Lab**, Department of Computer Science and Engineering, **University of Asia Pacific**. The designs are written in VHDL and simulated with **Xilinx ISE** running inside a **VirtualBox** environment.

**Course Teacher:** Md Rasheduzzaman, Lecturer, Dept. of CSE, UAP

---

## 🛠️ Built With

- **VHDL** : hardware description language
- **Xilinx ISE** : design, simulation and verification
- **Oracle VirtualBox** : virtual machine running the toolchain
